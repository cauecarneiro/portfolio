# Portfólio de Cauê Carneiro

Página única (HTML, CSS e JS, sem build). Animações com GSAP e ScrollTrigger via CDN.
Preto, branco e cinza, com azul puro (#0000FF) como único acento.

Fontes dos dados: repositório antigo `Portifolio`, GitHub, pastas do Frila, Carteiro, Overview-Painel e demais projetos.
Não entram: telefone, contas, chaves, finanças e assuntos pessoais.

## Publicação

- `index.html` é o trecho-fonte (também usado no artefato do Claude).
- `./build.sh` gera `docs/index.html`, o documento completo servido pelo GitHub Pages (branch `main`, pasta `/docs`).
