Política de privacidade

OpenBot Gmail · atualizada em 24/11/2026

O OpenBot Gmail é uma integração pessoal, feita e usada só por Cauê Crillanovick, que liga a conta Gmail dele ao assistente de IA que roda no computador dele. Não é um produto aberto ao público.

Quais dados são acessados

Com a autorização do próprio dono da conta, a integração pode ler, buscar, rotular e enviar e-mails da conta Gmail dele, pela API oficial do Gmail.

Como os dados são usados

  • Só para tarefas que o dono da conta pede ao assistente, como resumir e-mails, achar mensagens ou preparar respostas.
  • Nenhum e-mail é enviado sem a confirmação dele.
  • Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Onde os dados ficam

As credenciais de acesso ficam guardadas só no computador do dono da conta, em arquivos protegidos. Não há servidor próprio que armazene e-mails.

Como revogar o acesso

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
